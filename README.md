# PR Ready SG

A guided browser tool (start page, then Household → Documents → Submission pack) that helps households prepare a Singapore Permanent Residence application on ICA's e-PR e-Service.

- Per-person document checklist based on ICA's published checklist
- Date windows (employment letter, pay slips), fee estimate, who-does-what timeline
- Passport photo size and background check
- Submission pack: files renamed and numbered in checklist order, plus a summary sheet with pre-submission checks (Singpass readiness, document status), downloaded as one .zip
- Applicants always submit themselves on ICA's e-Service with their own Singpass
- Answers and attached files are stored only in the visitor's browser (localStorage and IndexedDB). Nothing is sent to a server.

Not affiliated with ICA. Always confirm requirements at https://www.ica.gov.sg before submitting.

The site is one static file: `index.html`.
